Cinder

Control panel notes for a Paper Minecraft server on Windows 11, and the Nokia Beacon 2 port forward.

Run the server

  1. On the Windows 11 PC, install Temurin 21 from adoptium.net. Tick Add to PATH.
  2. Put CinderHost.exe in any folder. If you changed settings in the panel, put cinder.json in that same folder.
  3. Double-click CinderHost.exe.
  4. The first time, type AGREE to accept the Minecraft EULA.
  5. When the console says Done, type op YourMinecraftName.
  6. People in the house use the PC IPv4 address. People outside need TCP 25565 forwarded on the Beacon, then your public address.
  7. Stop the world by typing stop.

Do not forward port 25575.

Nokia Beacon 2

  1. On the PC, run ipconfig. Write down the IPv4 address and the Default Gateway.
  2. Port forwarding is off if the Beacon is in Bridge mode. Forward on the ISP modem instead if it is bridged.
  3. Nokia WiFi app: Settings, Advanced, Port Forwarding, Create a rule. Name Minecraft. IP is the PC address. External and internal port 25565. Protocol TCP.
  4. Or in a browser on the Beacon Wi-Fi: http://192.168.18.1 (or the gateway from ipconfig, or http://www.webgui.nokiawifi.com). Sign in as admin with the sticker password. Application, Port Forwarding. WAN port and LAN port 25565, protocol TCP, Enable Mapping on, then Add.
  5. Friends outside the house use the public address on the Beacon WAN page, not 192.168.x.x. If that WAN address starts with 100.64, 10., or 192.168, the ISP is using CGNAT and a home forward will not work.
